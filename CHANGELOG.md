# Changelog

## [0.2.0] - 2026-11-06

- Add local folders, HTTP services, ErvisioDrive, ErvisioRepo and S3 destinations; shared source/destination pickers, protected credentials, optional ErvisioLogs events and explicitly scoped retention.


## [0.1.0]

- Initial Classic and ErvisiOS backup manager for folders, PostgreSQL,
  MySQL/MariaDB and SQLite snapshots to saved SFTP/SMB connections.
- Persistent schedules, manual background runs, exclusions, bounded private
  spooling and authenticated retention/recovery.
